# Interface Principal

A interface principal é organizada em menus superiores, canvas central, painéis laterais e painéis flutuantes opcionais.

[Áreas marcadas](../imagens/MangaTypesetter.png)

## Áreas Principais

### Menu Superior

Menus principais:

* `Arquivo`: novo projeto, abrir, salvar, exportar.
* `Editar`: desfazer, refazer e ações comuns.
* `Ferramentas`: ferramentas de canvas.
* `Textos`: ordem, glossário e tradução.
* `OCR`: ações de OCR.
* `Detecção`: detecção de balões/texto.
* `UI`: painéis flutuantes.
* `Configurações`: preferências do app.
* `Ajuda`: informações gerais.

### Painel de Páginas

Lista as páginas do projeto com thumbnails.

Uso:

* clicar em uma página para abrir;
* navegar pelo capítulo;
* conferir ordem das páginas.

[Páginas](../imagens/Páginas.png)

### Canvas

Área central de edição.

No modo Paginado, mostra uma página por vez.

No modo Contínuo, mostra várias páginas em sequência.

### Painel de Layers

Mostra a imagem da página e as layers associadas.

Permite:

* selecionar layer;
* ocultar/exibir;
* bloquear/desbloquear;
* reordenar;
* remover.

[Layers](../imagens/Layers.png)

### Painel Propriedades / Automação

Tem duas abas:

* `Propriedades`: edita a layer selecionada.
* `Automação`: executa OCR por categoria.

### Painéis Flutuantes

Ativados em `UI`.

Painéis atuais:

* `Menu Info`: navegação rápida de páginas.
* `Menu texto`: edição compacta de aparência de texto.

[UI](../imagens/UI.png)

## Barra de Status

Mostra informações rápidas como:

* zoom atual;
* mensagens de ação concluída;
* APIs padrão em uso;
* estados de exportação ou automação.
